## 数据只维护一份

唯一行情输入为 `../Chapter11 - 股票日频收益率分析/data/stock_daily.parquet`。本章只读跨目录引用，不复制、重建或修改共享行情。若该文件缺失，先按第11章Notebook生成，不另建第二套预处理流程。

本次源文件6,888,585行、27列，日期2021-08-16至2026-08-13；采用全部可用历史。主排序字段`Dsmvtl2`是总股数乘A股价格的总市值2，单位千元；并非A/B/H按各自市场价格加总。收益用含红利可比价格比值计算。

## 教学口径

- 信号日：每月倒数第二个市场交易日收盘后。筛选当时A股、非填充、正常交易状态、有成交、价格和市值有效的股票。
- 排序：按市值、代码稳定排序，等数量分成G1至G5，G1最小；分别等权和按信号日市值加权。ALL为同池自建基准。
- 建仓：月末最后交易日收盘；新组合从下一交易日开始计算收益，月内权重随收益漂移。
- 执行日缺少成交或价格的预定金额留现金；持有期间缺失估值沿用历史最后有效价格，不按未来收益可得性删股票。
- 旧持仓月末按估值退出；停牌退出与涨跌停成交尚未完整模拟，诊断表列出受影响的权重。终止记录的退市回收尚未核验。
- 成本为买卖每边10bp的参数情景，按股票交易名义金额计费，首次建仓计入；在新一期首个收益日统一扣除，不是逐笔成交模型。
- 敏感性：每个信号日剔除市值最小10%后，重新分五组。G1成员定义随之改变。
- 第一建仓日2021-08-31，收益2021-09-01至2026-08-13，共1,198个交易日、60次建仓；59个完整持有月份及末期不完整月份。
- 小减大只作月度规模收益差，不称标准FF SMB，不连乘为可投资多空净值。全历史用于教学探索，未进行独立样本外检验。

## 运行

课程根目录执行（Windows）：

```powershell
.\.venv\Scripts\python.exe -m nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=600 "Chapter12 - 横截面排序与股票组合/notebooks/12_横截面排序与股票组合.ipynb"
```

macOS将解释器改为`./.venv/bin/python`。也可在VS Code选择课程`.venv`后从头执行。路径支持从课程根目录、本章目录和Notebook目录启动。全历史会建立日期×股票矩阵，比第11章单年分析占用更多内存。

然后进入本章`latex/`运行两次：

```text
xelatex -interaction=nonstopmode -halt-on-error chapter12.tex
xelatex -interaction=nonstopmode -halt-on-error chapter12.tex
```

Notebook使用现有pandas、NumPy、PyArrow、Matplotlib、Jupyter依赖；本次没有安装新依赖。中文字体优先微软雅黑，macOS可用苹方。本次实际执行与PDF核验在Windows完成。
