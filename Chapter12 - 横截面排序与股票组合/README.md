## 数据和假设

唯一行情输入：`../Chapter11 - 股票日频收益率分析/data/stock_daily.parquet`。跨目录读取全部可用历史，不复制行情。数据从2021-08-16至2026-08-13，首尾年份不完整。

- 主规模字段`Dsmvtl2`为总股数乘A股价格的总市值2，单位千元；不是A/B/H分别按各自价格加总。
- 月末倒数第二个市场交易日收盘形成信号，最后一个交易日收盘建仓，从下一交易日计算新组合收益。
- 信号日保留正常交易状态、市值和历史估值有效的A股；不按个股当日成交量、未来收益或未来存续筛选。
- 含红利可比价格转成日期×股票矩阵，统一`ffill()`后直接使用。首次有效价格之前无法填充，因此信号日须已有正的估值。
- 假定调仓日按当日估值完成全部买卖，不考虑停牌、涨跌停和成交限制；各组全部资金投入股票，权重合计为1。
- 按市值、代码稳定排序，等数量分为G1至G5，G1最小；分别等权和按信号日市值加权，月内买入持有。
- ALL为同池自建基准；小减大为月度规模收益差，不称标准FF SMB，不连乘为可投资多空净值。
- 微盘敏感性每期先剔除市值最小10%，再重新分五组。

首次建仓为2021-08-31，收益从2021-09-01开始；最后一个不完整月份持有至文件末日。全历史用于教学探索，不是独立样本外检验，也不代表实际可实现交易业绩。

## 运行和编译

Notebook共38个单元格，其中19个代码单元格已在课程`.venv`中从头执行通过。使用PyArrow读取共享Parquet；生成6张图和14张汇总表，其中1张图、3张表属于末尾选学部分。PDF已编译并检查全部32页。

在VS Code选择课程`.venv`，从头执行Notebook；支持从课程根目录、本章目录和Notebook目录启动。

Windows从课程根目录执行：

```powershell
.\.venv\Scripts\python.exe -m nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=600 "Chapter12 - 横截面排序与股票组合/notebooks/12_横截面排序与股票组合.ipynb"
```

macOS解释器路径为`./.venv/bin/python`。进入本章`latex/`，运行两次：

```text
xelatex -interaction=nonstopmode -halt-on-error chapter12.tex
```

课件末尾包含选学部分，完整编译须执行第11节。图表和`analysis_numbers.tex`、`annual_table.tex`由Notebook生成；修改参数后重新执行并编译，同时核对固定日期案例和文字结论。
