## 数据和规则

只读引用 `../Chapter11 - 股票日频收益率分析/data/stock_daily.parquet`，不复制行情。该本地CSMAR文件共6,888,585行，覆盖2021-08-16至2026-08-13；原始数据不随Git发布，需要已有课程数据。

| 信号 | 定义 | 高分组含义 |
|---|---|---|
| 20日收益 | 含红利价格 `P / P.shift(20) - 1` | G5为短期动量，G1为短期反转 |
| 跳月动量 | `P.shift(20) / P.shift(120) - 1` | 较长窗口收益高；不是经典12–2动量 |
| 低波动 | 60日有效收益的样本标准差乘√252，再取负号 | 波动率低 |
| 低换手 | 20日日换手率均值，再取负号 | 交易活跃度低 |
| 排名合成 | 跳月动量、低波动、低换手三个同日百分位排名的等权平均 | 综合排名高 |

换手率用 `Dnshrtrd × Clsprc / (Dsmvosd × 1000)`；收盘价必须是未复权价格，流通市值单位为千元。它与组合调仓换手率不同，也不能直接代表交易容量。

- 共用沪深京A股候选池；信号日正常状态、非填充、正的有效市值与历史估值，四个原始指标均有效。
- 最近120日至少100个实际价格、60日至少50个有效日收益、20日至少15个换手观测。估值与动量使用前向填充价格；波动使用未填充价格的相邻日收益，缺失不当零收益。
- 月末倒数第二日收盘评分，月末最后交易日收盘等权建仓，下一交易日起计算收益，月内权重漂移。按分数、代码稳定排序分五组，各组人数最多差1。
- ALL为共同池自建等权基准。首次信号2022-02-25、建仓2022-02-28；收益2022-03-01至2026-08-13，共54次建仓、1,082个收益日；最后一个不完整月份只估值。
- 2025-01-01之前为开发段，之后为时间留出段。方向、窗口和等权合成规则在展示结果前固定；这是回顾性教学切分，已有课程使用过该历史，不能称为从未查看的独立检验。

## 本次结果如何解读

留出段合成组合累计收益26.53%，同池基准40.20%；最大回撤分别为−16.55%、−20.60%。合成并未同时改善收益与风险，不能先预设“多指标更好”。两段完整结果、五组曲线、排名相关和规模特征均保留在Notebook中。

全部为未扣成本的理想化回测，假设能按估值完成交易，未处理停牌、涨跌停和冲击。退市后延续最后价格可能遗漏清算损失；数据覆盖未证明无幸存者偏差。结果不构成实际可实现业绩或策略有效性证明。

## 运行与编译

在VS Code选择课程 `.venv`，从头执行Notebook。路径支持课程根目录、本章目录、Notebook目录。使用已安装的NumPy、pandas、PyArrow、Matplotlib、Jupyter组件，本次未安装依赖。

从课程根目录执行（Windows）：

```powershell
.\.venv\Scripts\python.exe -m nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=600 "Chapter13 - 横截面量价策略/notebooks/13_横截面量价策略.ipynb"
```

macOS将解释器路径换为 `./.venv/bin/python`。若Windows的Jupyter事件循环报错，可在运行 `NotebookClient` 前设置 `asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy())`；本次执行采用此设置。

进入本章 `latex/`，运行两次：

```text
xelatex -interaction=nonstopmode -halt-on-error chapter13.tex
```

Notebook生成6张课件插图、9张CSV表、`outputs/analysis_summary.json`，以及 `analysis_numbers.tex`、`signal_example.tex`、`development_table.tex`、`holdout_table.tex`。`outputs/`沿用项目忽略规则；持久核验记录位于本章根目录。课件教学页面均在主 `.tex` 中，其他TeX仅为自动生成的数值和表格。

修改参数后重跑Notebook、编译课件，并复核固定日期、文字解读和本README。下一章可用 `outputs/tables/daily_returns.csv` 作为组合收益入口，与无风险利率、因子序列按日期对齐。
