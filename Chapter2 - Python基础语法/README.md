## 类与对象：面向对象入门

Notebook 第8节放在函数之后；原综合案例与课后任务顺延为第9、10节，课程章节编号保持不变。

- **核心（8.1—8.15）**：从字典和函数到矩形类，区分类与实例、属性与方法，解释 `self`、`__init__`、返回值、状态修改和对象引用；再用 `StockPosition` 计算与更新持仓市值、未实现盈亏。
- **选学（8.16—8.19）**：继承与 `super()`、方法重写、多态，以及用组合组织股票与现金。
- **复盘（8.20—8.21）**：何时使用类、函数或字典，如何读懂常见报错。
- **练习**：矩形周长、引用与修改、持仓汇总、股票与现金组合；Notebook 参考答案折叠展示，课件答案集中放在本节练习之后。

本节仅使用 Python 内置功能，不需要新增依赖或外部行情。矩形尺寸和持仓数据均为自编教学示例；价格为元/股、数量为股，市值与盈亏为元，暂不计费用、分红和交易。Notebook 与课件采用相同代码及输出，并包含类与实例关系图。首次授课可先完成核心内容与练习1—3。
