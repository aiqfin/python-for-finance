模块以 Jupyter Notebook 为唯一载体，按主题分目录组织：根目录存放单文件练习（如 01~05 系列），子目录 05_Auto_MPG、06_US_Baby_Names、07_Tips 则把每个练习与其配套 CSV 数据分离存放。每个练习 notebook 采用统一的“Step N”结构：markdown 描述任务 → 空 code cell 留给学生填写，部分练习还附带带答案的版本（如 Exercises_with_code_and_solutions.ipynb、Solutions.ipynb）。数据源来自本地 CSV（chipo.csv、crime.csv、drinks.csv、tips.csv、US_Baby_Names_right.csv、cars1.csv/cars2.csv）或远程 URL（UCI Auto-MPG、Seaborn tips），无外部代码依赖，仅依赖 pandas、matplotlib、seaborn 等标准数据科学库。
