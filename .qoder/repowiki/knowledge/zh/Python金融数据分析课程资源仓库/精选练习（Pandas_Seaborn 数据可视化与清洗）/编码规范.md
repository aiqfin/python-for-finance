- 每个练习 notebook 使用“### Step N.”编号的 markdown 单元格逐步描述任务，随后紧跟空的 code cell 供学生填写。
- 同一主题练习将 notebook 与配套 CSV 数据放在同名子目录中（如 05_Auto_MPG、07_Tips），便于随练随用。
- 针对每个练习提供两套 notebook：空白版（Exercises.ipynb）与含解答版（*_with_solution*.ipynb 或 Solutions.ipynb），方便自学与对照。
- 数据读取统一通过 pandas 的 `read_csv` 完成，既支持本地相对路径也支持 GitHub raw URL。
