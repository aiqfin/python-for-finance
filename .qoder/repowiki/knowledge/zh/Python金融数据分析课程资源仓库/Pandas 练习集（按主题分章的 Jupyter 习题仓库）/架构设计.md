仓库采用纯文档/教程型结构，没有可执行代码包或构建脚本，所有内容由 Jupyter Notebook 构成：
- 根目录 README.md 作为导航总表，列出 10+ 个主题章节（01_Getting_&_Knowing_Your_Data 到 11_Indexing），每个章节对应一个编号前缀的文件夹。
- 每个章节下再按数据集/场景拆分子目录（如 Chipotle、Occupation、Euro12、US_Crime_Rates 等），子目录内通常包含 Exercises.ipynb（题目）、Solutions.ipynb（无代码答案）以及带注释的 Exercises_with_solutions*.ipynb（含代码解答）。
- 部分章节附带原始数据文件（.csv、.data、.desc 等），供 Notebook 直接读取。
- 依赖通过根目录 requirements.txt 统一声明（pandas==0.23.4、numpy、matplotlib、seaborn），运行方式即安装依赖后用 Jupyter 打开各 Notebook。
- 模块之间无代码级依赖，章节间为并列关系，仅通过 README 串联学习顺序。
