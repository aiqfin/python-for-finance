本模块由4个独立的Jupyter Notebook组成，按章节顺序编号（02~05），每个notebook对应一章课件：02_Python_Basics.ipynb（Python基础）、03_NumPy.ipynb（数组计算）、04_pandas.ipynb（数据表操作）、05_Visualization.ipynb（Matplotlib绘图）。各notebook之间无代码依赖，但内容呈递进关系——05_Visualization复用04中构造的模拟股票DataFrame作为绘图数据。所有notebook采用统一的markdown+code单元格结构，通过中文markdown注释讲解概念，配合可运行的代码片段演示用法；最终在05中生成prices.png作为示例输出图片。
