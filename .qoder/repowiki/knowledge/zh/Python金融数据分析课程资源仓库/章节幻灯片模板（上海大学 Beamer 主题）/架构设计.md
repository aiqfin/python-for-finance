模板采用单文档 + 外部样式分离的结构：
- chapterN.tex 为主入口，使用 ctexbeamer 文档类并通过 \usepackage{style/shubeamer} 加载主题样式，\input{style/macros.tex} 引入数学宏。
- style/shubeamer.sty 是核心主题包，集中定义配色（shublue/shusky/shugold 等）、背景水印、帧标题/页脚/封面模板、列表与 block 样式、以及 Python 代码的 listings 风格 shupython。
- style/macros.tex 提供向量/矩阵/张量/范数/算子等 LaTeX 数学命令。
- figures/ 存放正文图片，通过 \graphicspath{{figures/}} 自动搜索；logo/ 存放校徽与背景 PDF 资源，被主题包通过 \pgfdeclareimage 引用。
- reference.bib 配合 natbib + gbt7714-2005.bst 生成参考文献。
依赖方向单向：chapterN.tex → shubeamer.sty → logo/*.pdf / style/gbt7714-2005.bst，无反向依赖。
