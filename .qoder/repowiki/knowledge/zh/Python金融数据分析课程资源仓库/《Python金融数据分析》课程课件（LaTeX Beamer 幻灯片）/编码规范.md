- 每章幻灯片以 `chapterN.tex` 命名，统一通过 `\usepackage{style/shubeamer}` 加载主题，并在导言区集中定义颜色、字体与宏包。
- 图片路径统一通过 `\graphicspath{{figures/}}` 声明，引用时省略扩展名直接写文件名。
- 章节内容按 `\section{...}` 组织，配合 `\AtBeginSection[]` 自动生成目录页。
- Python 代码块使用 `listings` 的 `shupython` 样式，保持关键字蓝色、字符串金色、注释灰色的一致语法高亮。
- 第6章的图表由独立的 `_make_figs.py` 脚本生成，固定输出到 `figures/fts_*.png`，再被 `chapter6.tex` 引用。
