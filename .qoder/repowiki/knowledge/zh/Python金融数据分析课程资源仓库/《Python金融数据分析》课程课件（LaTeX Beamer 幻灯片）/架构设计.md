每个章节独立一个目录（Chapter1~Chapter6 slides），结构完全一致：
- `chapterN.tex` 为幻灯片主文件，基于 `ctexbeamer` 文档类，通过 `\usepackage{style/shubeamer}` 引入统一主题。
- `style/` 子目录包含共享的 `shubeamer.sty`（定义配色、页眉页脚、代码高亮等）、`macros.tex`（数学宏）和 `gbt7714-2005.bst`（参考文献格式）。
- `figures/` 存放章节配图，`logo/` 存放校徽与背景 PDF。
- 编译产物（`.aux`, `.log`, `.pdf`, `.bbl` 等）与源文件同目录。
- 第6章额外提供 `_make_figs.py`，用 matplotlib + pandas + numpy 从 `eod_data.csv` 生成真实金融数据的 PNG 插图。
- 依赖方向单向：`chapterN.tex` → `style/shubeamer.sty` / `macros.tex` → 外部字体与图片，章节之间互不引用。
