- 每个Jupyter Notebook以两位数字前缀命名（如01_why_python.ipynb、13_a_statistics.ipynb），与章节号一一对应便于检索。
- dx包内所有类继承自object并采用三引号docstring描述Attributes与Methods，方法命名使用snake_case且参数名与属性名保持一致（如initial_value、volatility、maturity）。
- 市场参数统一通过market_environment类的add_* / get_*键值对API存取，constants/lists/curves三字典分离不同类型数据。
- 估值器通过字符串形式的payoff_func接收收益函数（如'np.maximum(maturity_value - 100, 0)'），由eval或exec在上下文中求值，避免硬编码具体衍生品逻辑。
- 蒙特卡洛模拟通过fixed_seed参数控制随机种子，delta/vega等希腊字母采用向前差分数值近似并限制结果范围（如delta裁剪到[-1,1]）。
