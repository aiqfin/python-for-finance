本模块为纯教学练习集合，按主题编号（01~07）组织：根目录存放独立的单文件 Notebook 练习（如 01_Chipotle、03_Alcohol_consumption、04_US_Crime、05_Numerical_exercise），每个 Notebook 附带对应的 CSV 数据文件（chipo.csv、crime.csv、drinks.csv）；部分主题（05_Auto_MPG、06_US_Baby_Names、07_Tips）以子目录形式组织，内含 Exercises.ipynb 题目、配套 CSV 数据以及可选的 Solutions.ipynb / Exercises_with_code_and_solutions.ipynb 参考答案。所有 Notebook 均以 markdown 单元格描述步骤说明，code 单元格留空或仅含 import 语句，供学习者自行填充代码。
