本模块为扁平化的教学代码目录，由按章节编号的 Jupyter Notebook（01_Why_Python.ipynb → 15_trading_strategies_b.ipynb）构成主内容，辅以共享工具脚本 bsm_functions.py（Black-Scholes-Merton 欧式期权定价、Vega 与隐含波动率计算）和两份示例数据文件（fxcm_eur_usd_tick_data.csv、tr_eikon_eod_data.csv）。Notebook 之间无显式依赖，各自独立运行；bsm_functions.py 通过相对路径被相关 Notebook 导入使用。数据文件以 CSV 形式提供，供 pandas 直接读取演示 ETL 流程。整体结构遵循教材章节顺序，属于纯演示型代码组织，无包管理或构建系统。
