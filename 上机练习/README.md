面向金融专业学生。目标是读懂代码、修改参数、解释输出，不追求复杂算法或从零开发程序。前5周用可手算的合成数据，第6—8周复用第11章真实股票收益率数据。

## 使用方法

1. 在VS Code或Jupyter打开当周Notebook，选择课程根目录 `.venv` 解释器。使用课程已有的NumPy、pandas、Matplotlib与Jupyter，不新增依赖。
2. 从头运行准备与小示例；先读“输出解释”，再做题。每题含任务、代码起点、文字作答位置和折叠参考答案。
3. 练习中的待补全表达式先作为注释保留，因此原始文件可以顺序运行。学生需取消相应注释、替换省略号并补充代码，不能把“运行没有报错”当作“完成作业”。
4. 每题从准备数据独立开始，不依赖上一题是否答对；每周也可独立运行。修改准备参数后，从准备单元格重新执行。
5. 运行目录支持本课程根目录、`上机练习/` 或 `上机练习/notebooks/`。第6—8周的路径与字体设置由教师提供，不要求默写。
6. 提交完成后的Notebook，保留计算输出、图表和文字解释；最后重启内核，顺序运行自查。参考答案不是可执行代码单元格，需要自行复制到练习位置核对。

## 真实数据准备

后三周共用 `data/stocks_2025.csv`，由[教师提取脚本](scripts/prepare_data.py)从第11章现有Parquet生成。学生只需教师提供的这个小CSV，不必处理全量文件。来源、单位、筛选条件和运行命令见[数据说明](data/README.md)。

当前摘录：2025-01-02至2025-12-31，000001、600000、600519三只股票，共729条股票日记录，每股243条，共同有效日期243个。原选取范围783条，按第11章口径筛选后保留729条。三股日期完整一致；更换样本时需重新检查，不可删去中间缺失日后仍称为完整持有期收益。

收益计算使用 `Dretwd`，不以未复权价格变化替代含红利收益。累计收益包含首个样本日日收益，以该收益发生前本金1为基准。近似年化、复杂清洗与交易策略不纳入本阶段必做题。

## 练习顺序与评分

建议按“回顾与手算—阅读运行—补全与修改—迁移应用—解释与提交”的顺序完成。第7—8周的读取与准备单元格直接复用。

评分建议：解释代码与输出40%，补全和修改30%，结果及单位完整20%，Notebook组织10%。允许查课件和复用课堂代码；使用AI时说明用途，并能解释关键行、现场修改参数。不按代码长度或模型复杂程度加分。
