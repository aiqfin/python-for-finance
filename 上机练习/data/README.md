# 数据说明

第1—5周的小数据直接在各周 Notebook 中定义，为课程自行编写的教学数据，不是真实股票行情。

第6—8周共用本目录的 `stocks_2025.csv`。它来自第11章本地 CSMAR 授权数据的 `stock_daily.parquet`，只摘录2025年的 `000001`、`600000`、`600519`，不是实时行情，也不是全市场样本。原始来源和字段说明见第11章 README 及 `data/raw/TRDNEW_Dalyr[DES][csv].txt`。

| 字段 | 含义与单位 |
|---|---|
| Stkcd | 六位股票代码；按字符串读取，保留前导零 |
| Trddt | 交易日期；每行是一只股票一个交易日的观测 |
| Clsprc | 未复权收盘价，人民币元 |
| Dretwd | 考虑现金红利再投资的日收益率，小数；0.01 表示1% |
| Dnshrtrd | 成交股数，股 |
| Dnvaltrd | 成交金额，人民币元 |

筛选顺序与第11章主口径一致：保留A股、非填充记录、有成交、正价格、有限且大于 -1 的日收益率；不另外剔除 ST 或极端收益。数据按股票代码、交易日期排序，不补零、不插值、不改写真实价格或收益率。提取脚本核对股票日期唯一、必要字段完整、三股有效日期一致。

教师在课程根目录运行一次：

```powershell
.\.venv\Scripts\python.exe .\上机练习\scripts\prepare_data.py
```

macOS/Linux 使用 `.venv/bin/python 上机练习/scripts/prepare_data.py`。源 Parquet 须已存在；没有该文件时，按第11章说明准备，或由教师直接提供本教学摘录。学生不必持有或读取全量源文件。

脚本会覆盖本目录同名教学摘录与 `sample_summary.json`，不修改第11章源数据。摘要记录提取范围、前后行数和各股观测数；更换股票或年份后需重新核对日期覆盖。

授权摘录及其摘要只保存在本地，已在本目录 `.gitignore` 中排除；由教师在原有机构授权范围内提供给学生。不要把摘录上传公开仓库。Notebook 中保存的基础预览不等于完整数据文件，运行仍需要本 CSV。

收益计算直接使用 `Dretwd`；`Clsprc.pct_change()` 只是未复权价格变动，遇到分红、送转等事件时不能替代含红利收益率。累计收益纳入首个样本日的日收益，基准本金1对应首个样本日收益发生之前，不是首个样本日收盘。
